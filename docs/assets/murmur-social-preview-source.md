# Murmur social preview

`murmur-social-preview.png` is the original built-in image generation output.
`murmur-social-preview.jpg` is the same 1774 × 887 (2:1) image encoded as JPEG
at quality 90 with macOS `sips`; it is below GitHub's 1 MB upload limit.
The uploaded image is configured in GitHub repository Settings → General →
Social preview. Committing an image or putting it in the README does not by
itself change that repository setting.

The repository URL is `https://github.com/BitL8-ByteShort/Murmur`. Link previews
use metadata from that page. Actual X rendering is a separate platform check;
no X post was created during this setup.

Reference: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview
