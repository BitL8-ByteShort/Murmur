# Murmur Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Use a single agent unless Chris explicitly requests delegation. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build local Mac dictation that reliably inserts spoken text into the active app, with Quick Talk, Keep Talking, and a microphone-driven bottom-center visualizer.

**Architecture:** Native SwiftUI settings and drawing, a nonactivating AppKit panel,
actor-owned speech adapters, and a coordinator that keeps recognition independent
of text insertion. Session IDs reject stale callbacks and utterance IDs prevent
duplicate insertion. Model downloads never change selection or start capture.

**Tech Stack:** Swift 6, macOS 26 SpeechAnalyzer/SpeechTranscriber, AVAudioEngine,
AppKit Accessibility, Carbon hotkeys, Core ML; FluidAudio first optional SDK,
MoonshineVoice/WhisperKit subject to separate validation.

**Spec:** [Murmur design](../specs/2026-09-30-murmur-design.md)

## Global Constraints

- macOS 26 or later; Apple Silicon for the first release.
- Local recognition; no cloud speech or cloud rewriting in version one.
- Apple Speech is the initial default; optional speech models are explicit downloads.
- No account, background recording at launch, raw audio retention, or telemetry by default.
- Model files live outside the repository under Application Support/Murmur/Models.
- Keep GitHub private until Chris explicitly approves making it public.
- Never automatically press Return, submit a form, send a message, or execute text.
- Preserve uninserted text for recovery; never silently drop speech or retry a paste.

## Review Focus

1. The user changes app or field mid-session: pause insertion and retain text (Task 4).
2. Clipboard is rich or changes during fallback: preserve all types; don't overwrite new copies (Task 4).
3. Escape, sleep, unplug, or permission revoke races preparation: capture stops and late events do nothing (Tasks 1–2).
4. Silence/noise/long audio: no hallucinated insertion, duplicated overlap, or unbounded queue (Tasks 1–2, 5).
5. Rebinding conflicts or key repeat: old bindings remain usable and only one session starts (Task 3).

## File map and shared contracts

Existing scaffold: `Sources/MurmurCore/{Preferences,SessionState,AudioMeter}.swift`,
`Sources/Murmur/{AppModel,MicrophoneMonitor,OverlayController,VoiceVisualizer,SettingsView,MurmurApp}.swift`.

Production units to add:

- Core: `SpeechTypes.swift`, `TranscriptAssembler.swift`, `AudioQueue.swift`,
  `ShortcutBinding.swift`, `TargetSnapshot.swift`, `ModelManifest.swift`, `TextProcessor.swift`.
- App: `DictationCoordinator.swift`, `CaptureService.swift`, `AppleSpeechBackend.swift`,
  `HotkeyManager.swift`, `ShortcutRecorder.swift`, `TextInsertionService.swift`,
  `RecoveryView.swift`, `ModelManager.swift`, `ParakeetBackend.swift`,
  `InputDeviceStore.swift`, `HistoryStore.swift`, `PermissionsView.swift`.
- Tests: one corresponding `Tests/MurmurCoreTests/*Tests.swift` file per pure unit,
  `Tests/MurmurIntegrationTests/` for deterministic adapter checks, and
  `docs/ACCEPTANCE.md` for actual OS/app/device evidence.

Contracts defined by Task 1 and used by subsequent tasks:

- `AudioPacket: Sendable` holds `sessionID: UUID`, mono `samples: [Float]`, `sampleRate: Double`.
- `Utterance: Sendable, Equatable` holds `sessionID: UUID`, `id: UUID`, `revision: Int`, `text: String`, `isFinal: Bool`.
- `SpeechEvent: Sendable`: `status(String)`, `utterance(Utterance)`, `failed(String)`.
- `SpeechBackend: Actor`: `prepare(sessionID: UUID, locale: String, report: @escaping @Sendable (SpeechEvent) -> Void) async throws`, `accept(_ packet: AudioPacket) async throws`, `finish() async throws`, `suspend() async`, `unload() async`.
- `CaptureService` is main-actor setup/teardown with a bounded worker: `start(sessionID: UUID, onPacket: @escaping @Sendable (AudioPacket) -> Void) async throws`, `stop()`.
- `DictationCoordinator` is main-actor orchestration: `start(mode: CaptureMode) async`, `finish() async`, `cancel()`, `handle(_ event: SpeechEvent)`.
- `TranscriptAssembler`: `update(_ utterance: Utterance) -> String?` returns newly final text once or nil; `reset(sessionID: UUID)`.

These are planned interfaces, not claims that adapters already exist. Keep the
real-microphone preview explicitly separate until the production path is ready.
